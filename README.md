# Dev 学习目录

这里用于执行 Python / C / C++ / Go / Rust 的 12 个月学习计划。

## 从这里开始

1. 阅读路线：[PROGRAMMING_LEARNING_PLAN.md](PROGRAMMING_LEARNING_PLAN.md)
2. 按月打卡：[LEARNING_CHECKLIST.md](LEARNING_CHECKLIST.md)
3. 检查本机环境：

```bash
bash dev/tools/check-env.sh
```

## 建议执行方式

- 每门语言新建独立项目目录，不要把练习代码全堆在一个文件里。
- 每个项目都写 README，至少包含安装、运行、测试命令。
- 每周提交一个可运行版本，并写一份复盘。
- 每个月最后一周只做验收、重构和总结，不继续堆新语法。

## 作品集目标

- Python：CLI 工具 + FastAPI 服务。
- C：数据结构库 + 文件型 key-value 存储。
- Go：可部署 REST API + 并发 worker。
- C++：线程池或日志库 + CMake 项目。
- Rust：CLI 工具 + 小型 HTTP API。
